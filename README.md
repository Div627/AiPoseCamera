# 映刻相机 · AiPoseCamera

原生 Android 相机，当前版本 **0.1.0-beta.11**（versionCode 24）。使用 Kotlin、Jetpack Compose、CameraX 与本地 MediaPipe，目前针对小米 17 / ARM64 开发。正式 0.1.0 尚未发布。

## 功能

- 更多菜单直接提供“扫一扫”和“设置”；独立设置页。黑白灰主题、深色主按钮与透明次按钮；拍摄助手采用紧凑消息流和一体输入栏。

- 人像 / 风景模式，默认风景；简洁全幅取景、单句动作提示、姿势照片参考。特写、半身和全身分别引导，近景不强制要求全身关节点。
- 风景点选主体，本地交互分割；默认保留景物、按主体大小居中或三分构图，可选择突出主体。常用倍率、可展开变焦刻度与双指变焦。
- 根据亮度分布保护高光、适度提亮暗部，暗景保持氛围；稳定横向边缘满足条件时提供单句三分构图建议。
- 默认自然自动调色，一级菜单提供自然 / 清透 / 暖调 / 黑白；品牌和调色参数收纳在二级面板。富士、柯达、理光、徕卡、Agfa 等共 15 款色彩近似。
- Android 13+ 取景、缩略图和全尺寸调色副本共用色彩立方体；保留原片，不插值放大。
- 原片保存后立即释放快门，后台成片处理最多两张；最近照片预览、原片对比、分享、继续拍摄。
- 可选稳定后自动拍摄、明确的“再拍一张”入口；主动导出脱敏诊断日志。
- HTTPS 扫码更新在扫码界面原位显示字节进度，可取消、重试、重新扫码；校验版本/签名后手动安装。区分网络、链接、文件和签名错误；公开 GitHub 附件支持官方 API 备用入口，无第三方镜像。

- 拍摄助手：本地对话项目、Markdown 回复、原生方案卡、风格一键带入相机；公开包明确使用本地规则规划，尚未接入云端聊天。
- 地点查询：城市确认或主动定位后，通过 Photon / OpenStreetMap 查询 30 km 内观景点、瀑布、海滩；按直线距离排序并打开地图。需联网，不核验天气、道路或开放状态。
- 个人 Vlog：分镜卡逐段录制或导入，在手机上按镜头顺序各取前 5 秒合成竖屏粗剪；可播放、保存相册。记录、素材、成片留在本地，未实现语义选片、配乐、字幕或情绪驱动自动精剪。

## 构建

需要 JDK 17、Android SDK 35；在本地 `local.properties` 设置 `sdk.dir`，或配置 Android SDK 环境变量。

```sh
./gradlew assembleRelease testReleaseUnitTest lintRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`。默认仅打包 `arm64-v8a`，启用压缩；当前 beta 使用本机 debug 签名。不同开发者的 debug 签名不同，不能保证覆盖已有安装。

默认构建不含个人 API Key，人物识别、构图和调色均在本地完成。云端摄影建议需要自行配置服务。个人测试可在忽略的 `local.properties` 设置 `DEEPSEEK_API_KEY` 和 `QWEN_API_KEY`，并显式使用 `-PprivateBetaCredentials=true`；此类包不可公开分发。App 不提供密钥编辑入口。

## 验证与边界

当前 180 项测试通过（包含可选公开样片回放），lint 无错误。压缩发布包已在 Android 35 ARM64 模拟器输入公开照片验证人脸/姿态识别、拍照保存、缩略图预览及原片对比；尚未进行小米 17 真机验收。回放无法验证真实传感器、对焦、运动模糊或比赛评审结果，详见 [验证报告](docs/validation-beta.11.md)。预览帧的亮度和边缘统计只作为保守拍摄提示与自动快门约束，未实现闭眼识别、多帧择优、语义人像虚化或计算 HDR。

风格为自编近似，并非原厂算法或授权滤镜；尚未进行同场景原厂样片校准。来源和实现见 [风格研究](docs/camera-style-references.md)。最高分辨率取决于设备向 CameraX 开放的能力，不承诺特定像素数。

日志导出入口：相机更多设置或扫一扫右上角更多菜单。日志不含照片、密钥、二维码内容或模型回复，不会自动上传。
