# beta.13 验证报告

0.1.0-beta.13 / versionCode 26，ARM64 压缩公共包。实现与以下回放结论置信度高；小米 17 真机性能、触感、真实旅行素材的推荐美感与成功率未知。

## 实现和边界

- 聊天顶部“从视频选片”：流式导入512MB以下、十分钟内的视频，最多抽样90帧；本地图片标签、人脸与可用眼睛概率，结合边缘细节、曝光和近似重复检查推荐至多8帧。
- 推荐属于基础质量启发式，分数不是美感概率。眼睛概率缺失不当作闭眼。低质量画面不用于人脸摘要；仍可能存在模型误判。
- 原视频、抽样结果、候选预览、聊天、镜头卡和成片本地保存。编辑按时间点重新解码源视频，照片沿用共享风格LUT，可调整强度、比例和裁剪位置；保存实际尺寸，不上采样。解码长边4096、约850万像素预算控制内存，预览降采样。
- Vlog依据基础质量、时间分布、近似去重与连续抽样类别选2–6段，每段最多4秒。类别边界是抽样近似，不是逐帧精确场景检测。按源视频方向输出横屏/竖屏/方形，保留原声，可替换镜头。
- 摘要只描述抽样标签和人脸时间范围，不转写对白，不理解完整故事和情绪。由静到动仅参考人脸和亮度排序。没有自动音乐、字幕、电影叙事或比赛级照片效果证明；公开聊天仍是本地规划。

图片标签和人脸模型捆绑在包内，未使用动态下载版本。接口与依赖核对 [Google 图片标签文档](https://developers.google.com/ml-kit/vision/image-labeling/android) 和 [Google 人脸检测文档](https://developers.google.com/ml-kit/vision/face-detection/android)。没有在本次安装或评测 OpenStoryline、Remotion 或剪映 skill。

## 按钮验证

原生界面回放包含主按钮和快门按压、设置开关轻形变、合成/保存状态。触控区不靠缩小布局实现，动画集中在局部绘制。

- 合成期间显示“正在合成”，成功后显示“已生成”；保存后显示“已保存”，不由定时器伪造成功。
- 实际取消再次合成后按钮回到可生成，先前成片还在，临时pending文件已清理。
- 使用专门的临时验证项目与新建空项目验证删除：300ms按住松开仍显示确认说明，1200ms按住后项目从列表移除。没有删除其他项目。
- 修正并复测新对话残留上一项目“已保存”提示，项目切换后提示清空。

## Android实际文件回放

Android 35 ARM64虚拟设备；没有连接小米真机。用公开山景与人物照片构造15.083秒控制视频：前五秒暗且模糊，中段人物，末段清晰山景。它用于控制条件和文件链路回归，不是真实拍摄运动、审美盲测或旅行Vlog质量评测。

最终包实际导入并完成43帧分析，模型可用；推荐13.912秒山景和9.275秒人物，暗模糊段没有入选。人物抽样检出范围5.351–9.988秒。分析结果结束进程/覆盖安装后仍可读取。

实际编辑选中山景，应用冷调、1:1裁剪，保存到系统相册并关联原对话；回读JPEG为360×360，这是640×360测试视频裁剪后的真实尺寸，不是插值照片。截图验证横向裁剪只显示“左右”控制，没有无效的上下滑杆。

镜头卡实际关联同一源文件的5989–9989ms与11083–15083ms；预览按选中片段播放。实际本地合成输出H.264 1920×1080、无旋转标签，视频时长7.989333秒，AAC音轨7.987664秒。抽取成片起始和4.5秒画面，分别为人物与山景，暗模糊段未进入。源测试素材无声，因此此例只证明静音素材生成有效音轨，不证明真实原声质量；以前混合有声/无声素材验证见beta.10报告。

成片实际保存到系统相册，项目和成片在结束进程、覆盖安装后保留；原项目内照片关联仍存在。全程AndroidRuntime未见崩溃。
