# beta.10 验证报告

版本 0.1.0-beta.10，versionCode 23，ARM64 release，默认公共配置不含个人模型密钥。验证日期 2026-10-07。结论置信度：代码、构建、下述回放链路高；小米 17 实拍质量未知。

## 已实现和验证

- 相机进入拍摄助手；对话、方案、素材路径、照片引用、成片路径按本地项目保存。SQLite WAL，IO 线程读写。重启、覆盖安装后项目可恢复。
- 照片方案支持自然、冷调、暖调、黑白；卡片进入相机应用实际支持的风格并暂停自动换风格，继续自动曝光保护。回放验证冷调保持和照片保存到原对话。没有假装应用 ISO、快门或未经验证的摄影大师效果。
- 地点使用 Photon / OpenStreetMap 实时查询。应用内输入 Reykjavík / Iceland 后先确认国家地区，再返回附近观景点和海滩，包括 Ylströndin í Nauthólsvík、Skarfaklettur。仅发送主动查询的城市或位置，显示来源和直线距离。没有道路时间、天气、开放状态验证。
- 个人 Vlog 六镜头卡；实际 CameraX 录制 9.773 秒视频，导入 6 秒静音竖屏视频，在设备内 Media3 合成 10 秒竖屏粗剪。输出 H.264 / AAC，展示尺寸 1080×1920（编码尺寸与旋转 metadata 可能不同）。ExoPlayer 回放、系统相册保存均验证成功。
- 混合静音/带声音素材可合成，镜头按卡片顺序各取前最多 5 秒。取消或失败清理临时成片，保留原素材。没有语义选片、转场、配乐、字幕、自动节奏或情绪驱动精剪。
- 180 项 release 单元测试全部通过，无失败、错误或跳过；新增规划、项目往返序列化、非法方案与 500 条 Markdown 历史测试。lint 0 error、36 warning、3 information。
- 最终包标签、包名、版本、ARM64、模型原始完整性、16 KB 对齐与签名检查通过。与 beta.9 保持相同签名；release 压缩开启。

## 聊天与性能

公开版明确显示“本地规划 · 尚未接入云端 AI”，使用本地规则方案。现有个人构建接口可调用模型生成结构化方案，但本次公共包没有云端凭据，未验证云端回复效果。没有伪造流式输出；真实流式模型协议仍待接入。

列表初始 40 条、历史按 40 条加载，稳定消息 key；Markdown 后台解析、缓存，标题、强调、列表、表格、代码与链接为原生文字，方案为原生卡片；不执行 HTML 或自动下载外部图片。正在回复可停止、失败重试、复制文字。滚动不因风格选择或返回录制页强制跳到底部。

500 条本地历史回放没有崩溃。SwiftShader 无窗口 Android 35 ARM64 虚拟设备初步滚动统计：78 帧，18 个 janky frame（23.08%），中位帧耗时 25 ms、P95 81 ms。这个结果不能支撑“稳定 60 FPS”的结论，也不能代表小米 17 GPU 性能；长消息排版与真实设备性能仍需继续优化和测量。

## 环境和边界

只使用独立、忽略的 ARM64 Android 35 虚拟设备，CameraX 摄像头输入为公开照片与本地生成短视频。无连接小米 17 真机，未验证传感器画质、对焦、防抖、实际收音、发热和比赛评审效果。公开照片来源与许可沿用 [beta.9 报告](validation-beta.9.md)，短视频为本地 ffmpeg 合成测试图像及测试声音，不冒充用户拍摄素材。

compileSdk 升至 35 以满足 Media3 1.5.1，targetSdk 保持 34。当前 AGP 8.5.2 对 compileSdk 35 有兼容提示，构建已成功；后续工具链升级单独处理。

新增依赖：CameraX Video 1.3.4、Media3 Transformer / Effect / ExoPlayer / UI 1.5.1（Apache-2.0），CommonMark Java / GFM Tables 0.24.0（BSD-2-Clause）。地图标注 OpenStreetMap / Photon，公共 Photon 服务没有可用性保证。本次没有安装或宣称评测过第三方摄影 skill。
