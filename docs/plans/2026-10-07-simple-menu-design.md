# 更多菜单与单色按钮

用户明确要求简化扫码入口、独立设置页面，并采用黑色主按钮和白色文字、透明次按钮。本轮直接按此实现。

相机右上角“更多”展开两个动作：扫一扫、设置。扫码两次点击即可进入，不经过设置或维护分组。设置显示全屏标题与返回箭头，保留现有拍摄配置；诊断日志与版本信息直接显示，去掉维护分组的二次展开。设置展示期间暂停帧分析，防止后台计算和自动快门干扰；返回保持当前拍摄配置。

单色主题：白灰选中、无黄色填充。主按钮深色背景、白色文字与轻边框，次按钮透明；覆盖聊天、录制、扫码授权和安装操作。保留成功/错误状态色，避免把所有状态变成无区别的灰色。

备选是顶部额外扫码图标，但会增加取景页常驻控件；本轮选择用户提出的两项菜单。验证发布包的菜单直达扫码、设置返回、设置项交互和实际按钮截图，构建与 lint 后交付 beta.11 安装二维码。

追加：参考本机小虎 mobile release-dev 的 ChatScreen、UserMessage 与 Composer，简化助手标题、空状态、方案排版与输入栏；只借鉴交互结构，不复制其联网、附件或复杂选字机制。
