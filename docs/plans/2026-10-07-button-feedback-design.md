# 按钮反馈设计

用户授权参考小红书按钮视频改进现有交互。采用克制的按压、处理状态和开关形变，继续保持黑白灰主题；不加入核心流程没有用途的点赞粒子。

- 主按钮和快门按压时轻缩放，触控区域保持不变，执行不等待动画。
- 设置开关移动时滑块轻微拉伸，再收回；颜色与位置表示真实设置值。
- 视频合成和保存按钮原位显示处理中、真实成功或失败重试，进行中禁止重复执行。成功不依赖定时器伪造。
- 删除保留范围说明，确认按钮需按住900ms，进度可见，松开或移出取消。辅助功能保留明确的确认动作。
- 动画只影响局部绘制，固定按钮尺寸，避免带动列表布局或相机预览重绘。

验证压缩构建、现有单元测试、lint，并用原生界面回放按压、开关、取消和完成状态。实际小米触感不能由模拟器证明。新交付包继续 beta 递增，保持签名并核验下载二维码。
