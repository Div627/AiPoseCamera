# 简单拍摄与样片回放

产品目标：打开相机选择人像或风景，按一条动作提示调整后按快门。默认调色应保护肤色、高光和夜景氛围，不增加一级设置。

实现：亮度直方图保护曝光与暗部、统一亮度曲线、稳定边缘三分提示、未知检测状态不显示全身卡。模型初始化以压缩 release 包的真实相机链路为验收依据，补齐 Protobuf 和 Flogger 压缩兼容规则。照片预览保持深色界面和可见返回/分享入口。

验证：六组公开照片生产算法回放、九项新增确定性测试、Android ARM64 模拟器 imagefile 输入实际 APK 拍照与预览。结果与边界见 docs/validation-beta.9.md。保留原片；比赛级成片不是本轮能证明的结果。
