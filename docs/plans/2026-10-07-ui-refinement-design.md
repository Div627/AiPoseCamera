# beta.12 整体界面收敛

用户反馈 beta.11 的浮层、开关、设置文字、聊天顶部与可点击状态仍不精致。本轮按明确授权整体调整，并保留拍摄能力。

相机保留深色取景控制，中心文字入口换为聊天图标；左侧窄边缘向右滑可进入对话，不占用中央点选与双指变焦。对话以短横向滑动和淡入切换，240 ms，不增加逐字动画或常驻布局轮询。

聊天与设置改用浅色中性背景、深色正文、低对比次级文字。聊天顶部只保留返回相机、历史、新建图标，正文避免重复标题。可点击建议显示轻边框和箭头，地点操作显示明确按钮，不再像普通段落。输入栏统一容纳文字、麦克风与发送/停止。

设置按拍摄、取景、更多、关于分组。开关使用紧凑圆角轨道和短动画，整行可操作并保留 Switch 语义；延时折叠为当前值选择，不展示四个常驻按钮。版本为非交互值，操作行为用箭头。

语音使用 Android 系统识别入口，结果放入输入框由用户修改和发送，不做自动发送。识别服务、语言、联网及离线支持取决于手机系统；没有系统服务时显示说明并保留键盘入口。应用没有新增云端音频存储。

九宫格默认开启并保存关闭选择。水平线稳定到 ±2° 后变为确认色，250 ms 稳定进入只轻震一次；偏离 ≥4° 后再武装，1800 ms 冷却抑制重复震动。无传感器、隐藏设置、后台与拍摄时不主动触发反馈。

验收：压缩 APK 实际截图、图标/边缘入口、设置返回与配置持久化、系统语音不可用/取消、色彩与字号、网格默认和水平传感器回放；183 项测试、lint、签名与下载二维码校验。模拟器无法替代小米 17 的触感、真实语音服务和 GPU 流畅度验证。
