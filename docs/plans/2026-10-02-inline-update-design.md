# 扫码后原位更新

用户要求扫码下载恢复可用，并取消独立下载页。保留扫码入口，识别后停用重复扫描，在同一界面底部显示下载状态。相比独立页，它保留上下文；相比自动启动安装，它给用户清晰的完成状态和安装动作。

下载状态包括连接、字节进度、校验、可安装、取消和可恢复失败。返回/关闭可立即取消网络请求，不阻止退出。重试复用同一链接，重新扫码释放旧扫描锁。下载完成不主动跳转，只有用户点“安装更新”才调用 Android 系统安装器；未知来源授权返回后在原位继续安装。

网络错误、过期链接、网页响应、不完整文件、存储失败、无效 APK、包名、版本、签名不匹配分开提示，禁止展示原始异常或带参数 URL。公开 GitHub release 下载遇到连接错误时，可使用 GitHub 官方 API 找到同一附件的备用下载入口，不使用第三方 APK 镜像。下载请求可真正取消，半成品不提供安装；完成文件在校验后使用。

验证覆盖 HTTP 响应、重定向、截断文件、取消、错误分类、官方附件解析与包名/版本/签名策略；执行 release 构建、单元测试与 lint。真机网络不能用电脑验证替代。若手机无法访问公网下载源，提供单独的局域网浏览器二维码，明确它不能用于旧版 App 的 HTTPS 扫码更新。
