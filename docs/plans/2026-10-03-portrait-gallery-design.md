# 人像识别与相册按钮修复

用户反馈切换人像提示识别不可用，快门左侧相册按钮没有反应。

相册入口在没有最近照片时被禁用。改为有最近照片时预览、没有最近照片时打开系统图片选择器；预览中提供「查看相册」。图片读取仍在 IO 线程采样解码，不增加全相册查询或权限。

当前构图由本地人物检测 / 点选主体分割和规则引导组成，不等于多模态模型理解场景后选择最佳机位。

旧 MediaPipe 0.10.14 ARM64 ELF LOAD 对齐为 0x1000。更新至 0.10.32，其 ARM64 LOAD 对齐实测为 0x4000。新依赖没有携带旧 consumer ProGuard 规则，补入官方 JNI 保留规则，避免 Packet 回调方法与 SerializedMessage 字段被移除。模型 task / tflite 不压缩，避免重复解压。没有设备日志，不能证明页大小就是用户报错根因。

人脸与姿态初始化失败分开记录和提示，保留正常模块，提示可直接轻点重试；诊断增加数值 PAGE_SIZE 和失败模型编号。正常拍摄不依赖识别成功。

验证：release 编译、单测、lint、打包资产与 ELF 对齐、签名和线上下载一致性。当前没有连接 Android 手机，实机识别与点击流程待验证。
