# beta.12 验证报告

版本 0.1.0-beta.12，versionCode 25；ARM64 压缩 release 公共包，无个人模型密钥。代码与回放结论置信度高，小米 17 的真实语音识别、触感和 GPU 流畅度未知。

## 界面调整

聊天和设置使用浅色背景与深色文字，相机保留深色控制。实际截图核验系统栏文字对比、图标导航、可点击建议、原生 Markdown、按钮与麦克风输入栏。聊天顶部去掉标题/副标题，只保留 48dp 图标行。相机聊天图标直达，窄左边缘右滑进入；导航使用 240ms 横向滑动与淡入，未宣称设备帧率已达标。

设置分组展示拍摄、取景、更多、关于，延时收成当前值。紧凑开关有整行触控和 Switch 语义，文字与动作箭头层级统一。扫码菜单锚定右上角并保留两步直达。

## 拍摄辅助

九宫格默认开启，关闭选择保存到本地偏好。水平线在 ±2° 内显示绿色与中心点。稳定250ms才请求一次 CLOCK_TICK 触觉反馈；偏离4°后再武装，1800ms冷却。设置、拍摄、计时和后台不主动触发。

独立 Android 35 ARM64 虚拟设备回放重力/加速度：倾斜时白线，恢复水平为绿线；模拟器不能证明真实手机震动触感。新增 3 项门槛测试覆盖稳定进入、噪声不再武装、真实偏离与冷却、无效读数。

## 语音边界

麦克风入口调用 Android 系统 RecognizerIntent，转写放入输入框，用户确认后才发送，取消不自动发消息。系统服务是否联网、支持哪些语言与离线识别由手机决定；应用不保存录音，也没有增加云端媒体存储。

虚拟设备缺少语音识别服务，实际验证点击后显示“系统暂不支持语音识别，可使用键盘的语音输入”，无崩溃。尚未验证小米 17 的服务兼容和识别准确率。接口依据 [Android 官方文档](https://developer.android.com/reference/android/speech/RecognizerIntent)。

## 构建与发布

最终结果、APK 大小与校验值见下方核验记录。保持 beta.11 的包名和签名；没有修改拍照或视频处理算法，公开包仍未接通云端聊天。前版本的录制、导入、粗剪与保存验证见 [beta.10](validation-beta.10.md)。
