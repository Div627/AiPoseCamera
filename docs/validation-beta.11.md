# beta.11 简化交互验证

0.1.0-beta.11，versionCode 24。结论置信度：已记录的代码和虚拟设备交互高；小米 17 实机体验未知。

## 改动

- 相机三个点只显示“扫一扫”和“设置”。扫码从相机两次点击直达，不经过拍摄设置与维护分组。
- 设置改为独立全屏展示，顶部返回相机；现有拍摄指引、自动快门、延时、网格、水平与精细配置保留。版本、诊断日志直接显示。展示时暂停帧分析，避免额外计算和自动快门。
- 单色主题，选中状态以白灰对比和字重显示。主按钮为深色底、白字与轻边框；次按钮透明。覆盖拍摄方案、视频录制/合成、相机授权和安装更新。相机快门与成功/错误提示保留原本语义。
- 拍摄助手参考本机小虎 mobile 的 ChatScreen、UserMessage、Composer 结构：右侧用户气泡、助手正文、一体输入栏和发送/停止位置。标题紧凑、空状态使用无边框建议；本地回复不再重复方案卡的标题与全文。没有复制参考项目的联网或附件能力。

## 验证

Android 35 ARM64 独立虚拟设备，安装压缩 release APK。实际截图与 UI 节点核验更多菜单只有两项、扫一扫直达扫码页、设置全屏、切换九宫格后返回继续取景；对话新建、建议发送、方案按钮、输入栏和系统返回。

构建采用 `assembleRelease testReleaseUnitTest lintRelease`。结果见下方最终核验记录。不存在以单测替代真机画质验证的结论；这轮未修改拍照与视频处理算法。前版本地图、录制、合成验证见 [beta.10](validation-beta.10.md)。

公开包仍是本地规划，云端模型未接通。长历史保留分页与后台 Markdown 解析，未增加逐字动画或额外常驻刷新；没有小米 17 帧率验收。
